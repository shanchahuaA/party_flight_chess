## 二、游戏页

### HUD

- [ ] **G-01** `[改]` **HUD 顶部三钮** — 做法：进游戏页看顶栏。
      应见：回合 pill（`回合 5/15` 或 `⏸ 休息 8s [跳过]`）＋ 自己血量 pill（心形数字＋微条）＋ 右侧三个独立钮 `🎯 / 📖 / ⚙`；390×844 下不与棋子、战报带重叠。
- [ ] **G-02** `[回归]` **暗牌入口** — 做法：点 🎯。
      应见：浮层显示自己的暗牌目标卡（标题＋note）；观战态下仍可点开（淘汰不免除已达成的事实）。
      （浮层里再加「角色被动提示」属**可后置**，不进 M3 验收线。）
- [ ] **G-03** `[新]` **帮助速查** — 做法：点 📖。
      应见：底部浮层「规则速查」，**首屏一屏内可读完六块**：①目标 ②一回合三步 ③四类格子 ④环岛选路与来路栈退格 ⑤最后一波 ⑥结算五项；可上滑；不切页、不重拉数据。
- [ ] **G-04** `[新]` **局中设置** — 做法：点 ⚙。
      应见：浮层含 ①「📳 震动」开关（设备不支持 `navigator.vibrate` 时**整行隐藏**，不出现灰开关）②「🔊 音效」开关（见 §五）③房主额外见「成员管理」（见 G-07）④房主额外见「💥 解散房间」。**局中不出现任何数值配置**（数值一律冻结）。
      iOS 实测点：设置面板在 iOS 上不出现震动行，只剩音效 + 成员管理 + 解散，面板不显空。

### 新手引导

- [ ] **G-05** `[新]` **首次引导** — 做法：清 localStorage → 进房 → 开局 → 第一回合轮到自己。
      应见：掷骰前自动弹 **3 步**引导（①掷骰之后还没结束 ②战报在顶上 ③底下一条龙），每步一句话不超两行；有「跳过」与「下一步 / 开始游戏」；跳过或走完后 **本设备不再自动弹**；重看入口在大厅页脚「📖 规则速查」里。

### 观战与踢人

- [ ] **G-06** `[改]` **观战横幅** — 做法：让自己出局（被咬光血 / 或测试工具）。
      应见：棋盘顶部出现「☠ 观战中」横幅；**dock 整块消失**（不是灰化留位）、手牌消失；HUD 的 🎯 / 📖 / ⚙ 仍可用；棋盘与战报正常。
- [ ] **G-07** `[新]` **中局踢人** — 做法：房主在对局中点 ⚙ → 成员管理 → 对某真人点「请出」。
      应见：先弹**二次确认浮层**（「请出 阿强？他将失去本局，且无法再进本房间」，确认 / 取消）；确认后被踢者回到首页并看到被请出提示，其座位在后续房间态标为已请出；**假人行没有「请出」钮**；非房主看不到成员管理。

### 战报

- [ ] **G-08** `[新]` **条目展开卡面** — 做法：开全量战报抽屉 → 点一条带卡的事件/道具条目。
      应见：条目就地展开大卡面（叙事皮 flavor ＋ 效果 ＋ 选项），再点收起；不跳页、不关抽屉。
- [ ] **G-09** `[新]` **新条目 2s 高亮** — 做法：让一条新消息进让位带。
      应见：新条目底色高亮，约 2s 内渐出；旧条目**不做**透明度灰化。

### 棋盘联动（定案 §四 硬规格）

- [ ] **G-10** `[新]` **描边脉冲（normal）** — 做法：自己踩事件/陷阱、打道具落地。
      应见：触发者棋子金描边高亮约 1s（数据源可用 `MessageEntry.who` 派生，不必改内核）。
- [ ] **G-11** `[新]` **目标红脉冲（target）** — 做法：被弹弓/脚镣/惊雷一类指认型效果命中。
      应见：**目标**棋子红色脉冲，视觉比描边重一级（与 G-10 可区分）。
- [ ] **G-12** `[新]` **罚停加锁标** — 做法：踩香蕉皮被罚停。
      应见：棋子上出现锁标（与死亡灰化＋骷髅标区分）；dock 文案显示「本回合轮空」而**不是**「已确认 · 等待区」。

### dock 与手牌

- [ ] **G-13** `[回归]` **掷骰 / 确认分离** — 做法：掷骰后不点确认。
      应见：骰面回显在掷骰钮上；dock **不锁**，仍可打牌、做任务；直到自己点「✔ 确认结束」才进等待区并锁操作。
- [ ] **G-14** `[回归]` **超时替掷** — 做法：轮到某人时挂机到超时。
      应见：系统替掷并自动确认，战报出现对应系统条目，不卡局。
- [ ] **G-15** `[回归]` **手牌抽屉** — 做法：横滑手牌 → 点小卡。
      应见：半屏抽屉打开大卡（标题 / flavor / 路由 / 效果 / 打牌钮）；不可打时只出原因不出按钮。
- [ ] **G-16** `[回归]` **任务槽** — 做法：分别触发环岛选路、海关窗、抉择卡、选目标。
      应见：各自以任务条出现在 dock 上方，做完即消失。

### 音效（已定案，素材见 §五）

- [ ] **G-17** `[新]` **首次解锁** — 做法：冷启动 → 点「开始游戏」。
      应见：AudioContext 在该手势内 `resume()` 成功；之后掷骰即有声音。若浏览器拒绝，设置面板出现可点的「开启音效」而非静默失败。
- [ ] **G-18** `[新]` **音效只播自己身上的事** — 做法：4 人局。
      应见：别人扣血/抽卡不响；自己掷骰落定、自己扣血、轮到自己、自己得分、年兽出场响（对应 §五 A-07）。

## 三、结算页与局间

> **核心形态变更**：结算页从「联机下瞬闪的浮层」改为 **局间主舞台**。客户端用 `lastSettlement` 缓存驱动（`roomStore.ts` 已有该缓存），**服务端零改动**。

- [ ] **S-01** `[改]` **联机结算页停留** — 做法：联机打完一局。
      应见：服务端翻 `intermission` 后，**结算页仍然留在屏上**，直到自己点「回大厅」或房主开下一局；不再一闪而过。
- [ ] **S-02** `[回归]` **五项分项与排名** — 做法：看排名表。
      应见：每人一行，五格明细分项（进度 / 通关 / 存活 / 称号 / 整蛊）＋ 总分＋奖牌；同分按 pid 稳定排序。
- [ ] **S-03** `[回归]` **称号与暗牌亮牌** — 应见：达成称号显示金色 chip（自己那条高亮）；暗牌亮出「达成 ✓ / 未达成 / 作废」三态；群体失败时全员标作废。
- [ ] **S-04** `[回归]` **找战犯溯源** — 做法：点某条证据的「战报 #N」。
      应见：战报抽屉抬到结算页之上、定位到该条并闪光约 2.5s；无出手记录的缺席型显示「整局无出手记录」。
- [ ] **S-05** `[改]` **动作区吸底** — 做法：8 人局 + 长找战犯。
      应见：底部动作区 sticky 常驻屏底，**不需要滚到底**；滚动时内容不影响按钮可点。
- [ ] **S-06** `[新]` **房主局间改配置** — 做法：联机结算页，房主点「⚙ 改配置」。
      应见：浮层打开与大厅同一套 ConfigPanel（局长/血量/窗口/休息/计时/恶意强度/周期/假人数），改完确认 →「🎴 开下一局」→ 全员进入下一局抽暗牌；非房主在同页看到「等房主开下一局」＋当前配置摘要，无编辑钮。
- [ ] **S-07** `[回归]` **单机再来一局** — 应见：单机结算页「🔄 再来一局」按上局配置换新种子直开，外壳瞬时态（掷面/选择/脉冲/战报跳转）不带进新局。
- [ ] **S-08** `[改]` **回大厅** — 应见：点「🏠 回大厅」切回大厅；局间态下大厅仍显示上一局摘要 + 「回看战况」，供中途刷新/晚到的人落脚。

## 四、大厅与进房

- [ ] **L-01** `[回归]` **进房表单** — 做法：输 5 位房号＋昵称 → 加入。
      应见：进大厅且自己的座位在列；房号不足 5 位或昵称为空 → 内联报错，不提交。
- [ ] **L-02** `[回归]` **链接直达** — 应见：`?room=XXXX` 打开时房号自动填好。
- [ ] **L-03** `[回归]` **token 归队** — 做法：进过房 → 刷新页面。
      应见：静默归队回原座位，不要求重输；token 失效才落回表单。
- [ ] **L-04** `[回归]` **座位列** — 应见：真人 / 假人 / 在线·离线 三态可辨；房主有皇冠。
- [ ] **L-05** `[改]` **大厅踢人加二次确认** — 做法：房主在大厅点某座位「🥾」。
      应见：弹二次确认浮层（与 G-07 同一形态），取消不踢；确认后该座位消失且对方被拉黑。
- [ ] **L-06** `[回归]` **明选角色** — 应见：点角色卡即选中（全房可见、可重复选）；「ⓘ」开详情浮层（三轴 / 特长 / 被动）。
- [ ] **L-07** `[回归]` **配置面板** — 应见：房主改任一项 → 全员摘要在 1s 内同步；非房主打开为只读预览（无滑条、无保存）。
- [ ] **L-08** `[回归]` **开局闸** — 应见：不到 2 人时开始钮禁用并给提示；加假人后解除。
- [ ] **L-09** `[回归]` **抽暗牌** — 应见：房主开始后全员弹 2 选 1，选完才进游戏页。

## 六、跨页技术口径

- [ ] **T-01** `[回归]` **弹窗原则** — 应见：设置 / 帮助 / 暗牌 / 卡面 / 战报全量 / 抉择卡**全部是浮层**，没有任何一个查看类操作切页或重拉数据。
- [ ] **T-02** `[新]` **联机战报不截断** — 做法：联机打满一局 → 锁屏 2 分钟 → 回前台 → 开战报抽屉。
      应见：**能翻到本局第一条**（现状 `MESSAGE_TAIL = 200` 会把早期条目丢掉）；实现口径 = 首次快照发全量、后续消息发增量，不要简单加大尾片。
- [ ] **T-03** `[改]` **断线重连** — 应见：横幅三态（疑似中断 / 断开重连中 / 多次未成功）文案正确；恢复后 toast「已重新归队」，局内状态与战报完整。
- [ ] **T-04** `[回归]` **表情弹幕已砍** — 应见：全局搜索 `弹幕|表情|emote|chat` 在客户端零命中（本票确认维持 #10 的推翻条款）。
- [ ] **T-05** `[新]` **动效红线** — 只允许 CSS `transition/animation`、时长 ≤300ms，逐处点名四处：①新战报条目 2s 高亮渐出 ②扣血时血量数字弹一下 ③结算名次逐行淡入 ④骰面数字滚动。**不引入任何动效库**；超出这四处的动画一律归超级升级。

## 七、验收摘要（4 人真机当天用）

一次真机局的通过条件：

1. 四条主页面全流程走通，**零切页丢状态**（§二/§三/§四 全勾）。
2. 出现**至少一次**出局观战、**至少一次**中局踢人（可用假人局演练）、**至少一次**局间改配置开下一局 —— 三条最容易漏的路径必须各走一遍。
3. 音效在 iPhone 与 Android 各**至少有一台**实测出声；音量不刺耳、不叠音。
4. 全部「可后置」项允许不通过。
