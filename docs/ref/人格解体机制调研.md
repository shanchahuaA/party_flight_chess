## 1. 检定系统

### 1.1 骰子与基本规则（COC 式 1D100 低于值成功）

**帮助百科「骰子检定」**（`Game\HelpSystemData\2.txt`，原文摘录）：

> "当骰出的点数低于你需要检定的目标值时，该次检定成功。检定的目标值通常为调查员技能属性的数值，特殊情况下将会依托于所需的难度等级.
> 难度等级：成功（数值相同），困难成功（数值的二分之一），大成功（数值的十分之一）"

- 骰型：**1D100**。证据：`Assembly-CSharp.dll` 内 UI 字符串 "1D100"。
- 判定：**低掷优**——骰值 ≤ 目标值即成功（帮助原文"低于"；术语表 31/39 用"小于或等于"，实际为 ≤，与 COC 完全同构）。

### 1.2 档位规则（术语表）

| 档位 | 判定阈值 | 出处 |
|---|---|---|
| 普通成功 | 骰值 ≤ 属性/技能值 | 帮助系统 2 |
| 困难成功 | 骰值 ≤ 值的 1/2 | `TermData\39.txt`："如果掷骰结果小于或等于所选属性/技能的二分之一" |
| 大成功 | 骰值 ≤ 值的 1/10 | `TermData\31.txt`："如果掷骰结果小于或等于所选属性/技能的十分之一" |
| 大失败 | 骰值 ≥ (90 + 值/10) | `TermData\32.txt`："如果掷骰结果大于或等于（90+所选属性/技能的十分之一）" |

- 注意大失败**不是** COC 经典的 ≥96（非困难时）/=100，而是动态公式 `90 + 值/10`，即技能越高大失败线越靠后（值≥100 时不掷大失败）。
- 本职技能加成（`TermData\42.txt`）："每名角色的一项本职技能提升至最大值90，那么他在进行该技能检定时，**大成功区间增加5点**，**困难成功区间增加10点**。通过职业强化，可以将原本的非本职技能视为本职技能，同样享受上述加成。"
- 档位区间可被装备/Buff/特质调整。实例证据：
  - 物品 10669 高尔夫球杆："装备：使大成功和大失败区间均增加5点"（`Item\10669.txt`）
  - 特质"听天由命"："你的大成功和大失败的区间增加5点"（`Trait\10.txt`、升级版 `Trait\13.txt`）
  - Academia 目标区间：战斗内可叠"+3点，最多叠4层""+5点，持续到下次进入战斗"（Buff/技能文案）
- 成长检定（`TermData\38.txt`）："与常规检定相反，是需要针对（100-需要检定的属性或技能）进行检定。" 即值越高越难提升（低技能自 95+ 高概率成长）。

### 1.3 修正方式：奖惩骰（Advantage/Disadvantage 式）

**术语 33 奖励骰**（原文）："每有一个奖励骰，在检定时便会多投掷一次，并从所有投掷结果中取最低值作为检定结果。相同数量的奖励骰和惩罚骰叠加时，效果会互相抵消"

**术语 34 惩罚骰**（原文）："每有一个惩罚骰，在检定时便会多投掷一次，并从所有投掷结果中取最高值作为检定结果."

- 即 **D&D 5e 式 Advantage/Disadvantage**（取最低/最高），不是 COC 截断式 ±20 修正。
- 帮助系统 5：「奖励骰将会在所有结果中取最好的。而惩罚骰则相反」。
- 多重数量支持（1 枚以上叠作多 roll）。
- 数值加成通道是独立的：Buff/装备可直接 `+30` 修改目标值、`+1奖励骰`、`+2奖励骰`（例：鼓舞士气 Buff 627 = 智/意/敏 +30；闪避行动 = +2 奖励骰）。
- 状态型全体修正：精神状态影响所有检定（见 1.4），疯狂特质每 3 个 +1 惩罚骰（术语 16）。

### 1.4 状态门槛影响所有检定

| 状态 | 条件（原值） | 效果 |
|---|---|---|
| 精神充沛 | 精神 ≥70 | "精神值每高于临界值（70）1点，所有技能检定成功率提升1%（最高20%）"，每回合 +2 魔法值 |
| 精神衰弱 | 精神 10-29（<30） | 每低 1 点 -1% 成功率（最高 20%），施法免精神值消耗 |
| 精神衰竭 | 精神 1-9（<10） | 衰弱效果 + **所有检定 +1 惩罚骰**，每次成功施法回少量精神值 |
| 陷入疯狂 | 每激活 3 个疯狂特质 | 每层所有检定 +1 惩罚骰（术语 16） |

（出处：`TermData\35/36/37/16.txt` + `MOD_GlobalData.txt`）

### 1.5 幸运重掷与幸运强化

- **幸运强化**（术语 43）："在战斗中选择攻击或技艺行动后，点击角色旁的四叶草按钮，会进入幸运强化状态，**消耗 7 点幸运值**并使本次行动的技能检定成功率提升"。
- **幸运重掷**：消耗幸运值重骰（探索剧情检定可多次）；相关装备证据：`Item\1017` "首次重掷不消耗幸运"、`Trait\5` 每次重掷额外 +3 幸运消耗、`Item\5026` "结果必定困难成功，但改为消耗3点精神值"。
- 重掷固定消耗点数在 UI 层配置（DLL 有 `LuckCost` 符号），基础值表中未查到，标「未查到精确基础消耗」（战斗中固定 7 点见上）。

### 1.6 双人对冲：技能对抗

**帮助系统 4 原文**："角色之间的行动将会产生冲突，出现冲突时会显示技能对抗界面. **骰出更高一级难度等级的角色将会成功发起行动**."

UI 证据：DLL 包含 `Trans_CheckAgainst/Trans_MyDice/Trans_EnemyDice/Trans_NpcAgainstDice` 等对冲视图。

### 1.7 理智检定（SanCheck）

- 剧情触发层 `MOD_TextParserSaveData.txt` 内置指令 `^SanCheck(x)/(y)`，即 COC 式「成功失 x / 失败失 y 点理智」；另 UI 有 `Text_SanCheckFailText/SanCheckSucText`。

### 1.8 大成功/大失败的其他奖励（重点补充由帮助系统覆盖）

- **大成功 → 更强正面效果/额外收益**：直接例证（全部原文摘录）：
  - 全局（帮助系统 2 + 术语 31）："在战斗中，大成功通常会比普通的成功带有更多的正面效果"
  - 战斗行动有「强制大成功」招式：`BattleSkill\1017` 呼唤希望："本回合速度+100，进行意志检定，如果成功，则使本回合中所有友方的技能检定**必定为大成功**"。
  - 物品 10218 逗猫棒："如果你的交涉目标是猫猫，你的这次交涉检定**必定大成功**"（机制可通过配置强制）。
  - 获取收益级：大成功+幸运（+8 / +5）、获得【希望】层——见 §2 明细表。
- **大失败 → 有代价的负面**：
  - 全局（术语 32）："在战斗中，大失败通常会带来一定的负面效果"
  - 理智-5；失败扣精神-3 且**额外随机激活一项疯狂特质**；武器摧毁（`Item\1019` 棒球棍：攻击大失败时武器被摧毁）；直接倒地（`BattleSkill\1015` 切断丝线：失败使目标进入重伤状态）；`ItemProcess` 制作类行动 `BigFailureId=1044`（19 处配置，加工出废品分支事件）。
- 量级对照普通成功/失败：大成功是"额外正面效果"（额外收益、追加目标），大失败是"额外惩罚"（资产损失和随机疯狂特质），本体数值是**行为级**而非倍率级。

## 3. 战斗系统

### 3.1 回合流程（速度决定出手顺序）

- 基础速度 = **敏捷** 弹性调整。全局定义（`MOD_GlobalData.txt`）："初始的速度值取决于敏捷，而在战斗中采取不同的行动会影响速度的实际值，并最终决定在同一回合中的出手先后顺序"。
- 每个行动都改变本回合速度：徒手/妙手 +10、隐匿 +30、格挡 +40、蓄力 +40、顺劈/扫射 -20、魅惑 +50、呼唤希望类大招 +100~300（`BattleSkill\2-19`、`1000+` 系列原文速度 +N）。
- 速度条专用 UI 字段在 strings 扫描中未查到（速度独立展示未证），回合序通过战斗面板呈现。

### 3.2 命中 / 防御 = 攻击检定 vs 防御行动

- 攻击行动进行武器对应的技能检定（斗殴/射击，见 §4.2）；防守方不还击为常态，但可通过行动类防御（利用双方检定的对抗视图呼应帮助系统 4 的"技能对抗"）——攻击/闪避的具体对抗判定细节在数据表中未直述（推断为攻检定 vs 防检定的档位对冲，UI 存在双骰对照面板）。
- 防御性基础行动（`BattleSkill\7-11` 原文摘录）：诱敌（运动-心理学联合检定，撤销敌方单目标行动）/ 格挡（+5护甲，受近战后使敌人昏迷并立即反击）/ 闪避（+30速度，被动检定 +2 奖励骰，敌人行动后可感知检定给其挂【弱点暴露】）/ 隐匿（不被选为目标）。
- 其他主要行动：徒手攻击（速度+10，伤 1-3+DB，敏>50 双击）/ 使用武器攻击（副手武器 +1 惩罚骰）/ 蓄力（+40 速度，【攻击准备】：下回合攻击 +1 奖励骰、不被反击、普通/力量型武器命中必定最大伤害）/ 妙手 / 魅惑 / 急救 / 观察 / 投掷 / 逃跑。
- **闪避**由装备灵巧型武器解锁（术语 3、6）；**格挡**需护盾型；**顺劈**需力量型；**连射/扫射**需枪械型。
- 反击链：格挡状态被近战伤害 → 攻击者【昏迷】+ 立即反击；蓄力状态：下回合 +1 奖励骰不被反击 +必定最大伤害（`BattleSkill\8` 原文："装备普通型或力量型武器命中时必定造成最大伤害"）。

### 3.3 伤害公式（骰系 + 固定修正 + DB）

- 伤害表达式为骰式字符串：如 `"1D3+3"`、`"2D3+4"`、`"1D8+6"`、`"6+2D4"`（`Item\*`、`Magic\*`、`BattleSkill\*` 的 `Damage.Value` 字段）。
- 全量分布（本地 362 物品 + 法术 + 技能统计）：主流 `1D3`（38）/`1D4`（21）/`1D6`(16)；强者 `1D8+6`、`2D6`、`3D5`（6）、`4D6+5`、`5D5`。
- 基础攻（徒手）："造成 1-3 点基础伤害，**附加伤害加成**，随后本回合闪避+20"（`BattleSkill\2` 原文）；敏捷 >50 时额外攻击一次。
- **伤害加成 DB**（全局定义原文）："赤手空拳、所有近战武器及部分远程武器，会根据你的力量对伤害有额外的加成"，UI 词 = "为基础伤害的额外增加量，通常不适用于远程攻击"。COC 式由力量等导出（角色数据有独立 `DB_Extra` 字段，`Charator\1.txt` 中为 null；精确换算公式未查到）。
- **伤害类型/元素**：`DamageAttrInteraction` 表 27 条（火→燃烧、爆炸互抗等）。配表示例：手枪 `AddAttrs=[13]`（点火）+ `DamageType 0`（普通物理）。
- **法术伤害独立类型**（不适用护甲减免；燃烧/毒/流血每轮伤害）：
  - 枯萎术 `1D6+8` = 9-14 点法术伤害，困难成功及以上附第二目标 `1D6+4`（`Magic\1.txt`）
  - 巨镰收割 `6+2D4` = 8-14 点法术伤害，全体（`BattleSkill\1019.txt`）
  - 赤印术：每回合持续耗 4 魔法 → 全体 8 点法术伤害（`Magic\12`）。
- **伤害区间展示**：UI 文案用 `[1-6]` / `[6-10]` / `8-14点` 形式（= 骰式最小~最大）。注意样例：步枪 `2D3+4` 与文案 `[6-10]` 严格一致；手枪配置 `1D3+3`（4-6）但 UI 文案作 `[1-6]`，两处存在文案与配置口径不完全一致的样例（"必定最大伤害"状态仅作用于蓄力）。

### 3.4 防御机制

- **护甲 Armor**：全局定义："这是你对普通、爆炸伤害的防护"。物品/Buff 直接 +N（`Item\10504` 特制盾牌 +10；格挡 +5）。
- **受伤加深**：昏迷状态"受到的所有伤害增加5点"（`Buff\101`）；中毒"你造成的普通伤害减半"（`Buff\102`）。
- **护盾式 Buff**：血肉防护术（`Magic\2`）——受物理伤害时改为扣减伤害值一半的魔法值，向下取整，魔法值归零提前解除。
- **闪避 Dodge**：独立副属性（外部修正字段 `Dodge_Extra`，如 NPC 犹格索托斯 -500），是"角色在战斗中躲避敌人攻击的能力"（全局描述："你可以试着规避一些攻击，除了子弹这种东西"）。
- **防线/掩体**：观察周围环境行动成功 → 我方全体获得【掩体】状态（`BattleSkill\19`）。

### 3.5 血量与 SAN 双轨

- **生命值 HP**：全局定义原文："在你倒下之前，能承受的累计伤害量"。状态机：`正常 / 重伤 / 倒下`——"因一次不超过生命上限的攻击血量归零时，进入重伤状态，此时将获得一层骨折"（`MOD_GlobalData.txt` 原文；帮助系统 1亦有同源：“只要不一次性受到大于最大生命值的伤害，他将能抵抗一次超过当前生命值的伤害效果"）。
- 韧性机制 = COC 式重创（Major Wound）：一击伤害 ≤ 生命上限但把血扣到 0 → 进入重伤（获一层骨折），可被急救拉回正常；一击伤害 > 生命上限 → 无视"抵抗一次"直接倒下/死亡（帮助系统 1 原文："只要不一次性受到大于最大生命值的伤害，他将能抵抗一次超过当前生命值的伤害效果"）。
- **精神值 SAN**（双轨运作，与魔法值联动，见 §1.4）：
  - 70 / 30 / 10 三段门槛影响所有检定；
  - **施法替补**：魔法不足时可用精神值支付法术消耗（全局文本）；精神值 ≤0 时触发清零结算：随机激活一个疯狂特质，随后精神值**恢复至10点**（术语 16）。
  - 精神=0 且模组通关后**角色从角色库移除**（帮助系统 1："当精神值归零，模组通关后角色将会从你的角色库移除"）。
- **魔法值 MP**：每回合自动恢复（全局文本："释放法术需要的消耗，会随着回合数变化自动恢复"）。
- **SAN 检定链路**：剧情 `SanCheck x/y` 指令 + 攻击神话生物/目击神话、精神系伤害触发。

### 3.6 战斗规模与场数

- 无固定回合上限配置；基础行动 18 个；单战几轮取决于双方血量/速度配比，**未查到**「固定轮数」的配置字段；怪物元素用血量 30%-50% 削减选项可调整难度（`BattleEnhance\1-6.txt` 是官方内置战前增强选项：敌方 -HP / 我方变法伤 / +1 奖励骰 / +2 奖励骰）。

### 4.3 属性如何影响检定/战斗（总结）

- 检定 = 1D100 vs（技能值或属性值）+ 数值加成/减值（如鼓舞 +30）+ 奖惩骰数 + 精神状态百分比修正（§1.4）。
- 战斗导出量：
  - 速度 = 敏捷初始 + 行动修正（决定出手顺序）
  - DB = 由力量导出，仅近战/徒手（角色数据另有 `DB_Extra` 字段）
  - 闪避 = 敏捷系 + `Dodge_Extra` + 状态修正
  - HP 上限 = 体质系基数 + `HP_Extra` + 装备/状态加值（如白大褂"生命值上限+3"；怪物「虚荣」CON 180 / `HP_Extra` 39）——**精确换算公式未查到**
  - MP 上限 = 意志/体格系基数 + 加值（同上未查到公式，随职业不同 `MP_Extra`）
  - 护甲 = 装备 + 状态 (+N)
