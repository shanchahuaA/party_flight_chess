## 目录结构

```
/
├── kernel/            # 规则内核（纯 TS、无 DOM/IO——M1/M2 唯一复制边界；test/ 为意图序列+种子 RNG 测试集）
│   └── src/
│       ├── rng.ts     # 种子随机源（mulberry32）
│       ├── check.ts   # 检定框架（1d20 高掷优四档、极值取原始面、修正先互抵；T3a/T5/T6 消费）
│       ├── board.ts   # 棋盘静态数据：100 格庄园路网、生态三区、8 位出生槽池+按人数菜单、街名/地皮占位渲染数据
│       ├── types.ts   # 状态/意图/事实/战报类型（M2 时即 WS 消息协议的服务端形态）
│       ├── data/      # 内容数据（数值表落账真源）：roles.ts 角色表三、goals.ts 暗牌目标表四、events.ts 事件卡面 DSL+表二（21 卡；'window' 卡 T7 放行）
│       └── game.ts    # 内核推进：意图受理、tick 时钟、开局抽牌（drafting）、世界回合窗、走格/选路/退格/支路
├── client/            # Vue 3 + TS 前端（Vite）
│   └── src/
│       ├── board/     # SVG 棋盘层（格子几何、棋子、逐格动画）
│       ├── ui/        # DOM UI 层（大厅、dock、HUD、选路条、暗牌浮层，手牌与战报随后续票进）
│       ├── game/      # 内核接线（单机壳的对时/心跳/事实消费；M2 换 WS 时只动这里）
│       └── net/       # WS 连接、对时、快照恢复（重连的唯一入口，M2 落）
├── server/            # Cloudflare Worker 入口 + Room DO（M2 落）
│   └── src/
│       ├── index.ts   # Worker 入口：WS 升级，按房间码路由到 DO
│       └── room.ts    # Room DO：权威状态、Alarm 推进、Hibernation
├── shared/            # WS 协议类型、棋盘几何常量——两端共享的唯一真源（M1 期内核自带类型，M2 归并）
└── docs/
```

## 端口与本地开发

- `client`：`vite dev`，端口 **5173**，热更新。
- `server`：`wrangler dev`，端口 **8787**，本地模拟 DO（本地 SQLite 态）。
- vite 把 `/ws` 代理到 `ws://localhost:8787`——前端代码只写相对路径，感知不到双进程。

## 协议纪律

- 全部 WS 消息是 `shared/protocol.ts` 里的 discriminated union（`type` 字段判别），client/server 禁止各自手写消息类型。
- 上行 = 意图（掷骰、打卡、出道具卡、抉择选择、确认结束）；下行 = 事实（状态变更、回合号 + 截止时间戳）。演出（逐格动画、秒数）客户端本地播。
- 所有上行消息带 `turn`（客户端已知的回合号），DO 校验后才生效——防过期操作。

## CI / 部署

单个 GitHub Actions workflow（`deploy.yml`）三个 job：

1. **test**：kernel 规则内核单测（vitest；#17 起的首个测试集）。
2. **pages**：构建 client（`vue-tsc + vite build`）→ `actions/upload-pages-artifact@v3` + `actions/deploy-pages@v4` 发 GitHub Pages。
3. **worker**：`cloudflare/wrangler-action@v3` 部署 Worker/DO。仓库 Secrets：`CLOUDFLARE_API_TOKEN`、`CLOUDFLARE_ACCOUNT_ID`。

`wrangler.jsonc` 要点：`migrations: [{ new_sqlite_classes: ["Room"] }]`（免费层 DO 必须 SQLite 后端）；Worker 绑自有域名 custom domain。若 Pages 侧遇阻，可退到「Worker 静态资产单域名全包」方案（同样免费），部署任务实施时权衡。

## 域名（人工待办）

- `*.workers.dev` 大陆不可达，部署前须**购买一个域名**并托管为 Cloudflare zone，Worker 配 custom domain（免费层支持）。
- GitHub Pages 侧走同域子域（如 `play.<域名>` 静态页 + `sync.<域名>` Worker），具体取值在部署链路任务里定。
