# 事件卡系统定案（MVP）

> 来源：[事件卡系统与跑团感定案 #5](https://github.com/shanchahuaA/party_flight_chess/issues/5)。本文是该票的完整定案：系统规则、卡面数据结构草案、首批样卡清单。规则变更同步在《[MVP一页纸规则](MVP一页纸规则.md)》。

## 一、系统规则

### 1.1 卡面格式：抉择为主

- 事件卡以**抉择卡**为主（首批 14/20）：抽到后弹给**触发玩家本人**点选，一人一卡互不干扰；其他玩家通过**世界消息**看到结果。
- 其余为**纯效果卡**（首批 6/20）：抽到即自动结算，播报进世界消息。
- 涉及多个玩家的事件卡灵活处理：目标由**系统指认**（见 1.5），不要求双向协商。
- **跑团感来源定案**：跑团感来自「选」与「承担后果」，不引入真人主持人——事件卡系统即「系统主持人」。GM 模式属完整版话题。

### 1.2 文案基调：叙事皮 + 整蛊核

每张卡一句高塔场景短文案（借《轮回高塔》设定风味），效果落点欢乐整蛊。

### 1.3 道具卡打出时机：窗内任意时刻，确认即锁

- 引入文明 6 式**确认结束**：玩家完成本世界回合全部操作后点「确认结束」进入**等待区**，此后本回合不能再操作（含打卡）。
- **确认结束之前**，世界回合窗内任意时刻可打道具卡——包括掷骰之后、看到结算结果之后（重掷/补刀类卡有生存空间）。
- **手牌无上限**；**每世界回合打出张数不限**。⚠️ 本条推翻核心循环定案（#4）中「每世界回合至多 1 张」，平衡风险留原型实玩调。
- 超时替掷的玩家不打卡（沿用既有定案），系统替其掷骰并自动确认。

### 1.4 HP 与陷阱

- 每人 **血量上限 3**，UI 显示血条。
- 扣血来源：陷阱格（固定）与事件卡效果；道具池含治疗卡。
- **血尽 = 轮空**：原地跳过 1 个世界回合（不能打卡不能掷骰），结束后满血复活。永不出局，与「无人中途出局」定案兼容。
- **陷阱 8 格每格固定效果**（棋盘可见），陷阱是格子属性不是卡、不占牌池。

### 1.5 互动卡边界：整蛊进，合作不进

- 事件卡与道具卡都可含**指向他人**的效果，目标由**系统指认**（离终点最近的人、上家、随机等），首批含 2–3 张多玩家事件卡试点。
- 双向协商类（合作、交易、秘密目标）不进 MVP，留给「玩家对抗与交互机制」票（#10）。

### 1.6 指他人效果的生效时机：按计时模式分流

- **轮班·限时**：**立刻生效**（无同时行动，无竞态）。
- **世界·即时**：**下回合生效**（目标下一世界回合开始时结算），世界消息可见，被整蛊者有预判窗口。

### 1.7 抉择超时：卡面默认项

每张抉择卡数据带**默认项**字段（通常选安全/中庸项）。玩家超时、挂机或掉线时自动按默认项结算，并在世界消息标注「（代选）」。

### 1.8 牌堆结构：单池洗匀 + 地区特殊卡

- 事件卡**单池洗匀**，抽完把弃牌堆洗回；道具卡同理单池。
- 4 色分区暂不承载独立牌堆；分区差异通过**地区特殊卡**实现——带适用分区标签的卡，仅当抽卡者位于该分区时结算，否则洗回牌堆重抽下一张（等效于区域权重修正，不做独立权重表）。
  - ⚠️ 实现解释：如需独立权重表（红区负面概率整体上调），再改；当前按「地区特殊卡即修正」实现。

### 1.9 首批牌池规模：20 + 12 + 8

事件卡 20 张（14 抉择 + 6 纯效果，含 3 张地区特殊卡）＋ 道具卡 12 张（含 2 张治疗）＋ 8 个陷阱格固定效果。一局 4–8 人合计约 160+ 次事件抽卡，靠洗匀摊薄重复感；重玩 2–3 局不腻靠抉择分支 + 洗匀，腻了再加池。

## 二、卡面数据结构草案（字段级）

```ts
type Region = 'green' | 'yellow' | 'red' | 'blue';

interface EventCard {
  id: string;
  title: string;              // 卡名
  flavor: string;             // 一句场景文案（叙事皮）
  kind: 'choice' | 'effect';  // 抉择卡 / 纯效果卡
  region?: Region;            // 地区特殊卡：仅该分区结算，否则洗回重抽
  options?: CardOption[];     // kind=choice 必填，2 个
  defaultOption?: number;     // kind=choice 必填，超时/掉线代选（通常安全项）
  effect?: CardEffect;        // kind=effect 必填
}

interface CardOption {
  label: string;              // 选项文案（整蛊核落点）
  effect: CardEffect;
}

interface CardEffect {
  self?: EffectPart[];        // 对触发者/使用者
  others?: TargetedEffect[];  // 对他人（整蛊）
}

interface TargetedEffect {
  target: 'nearestToGoal' | 'farthestFromGoal' | 'previous' | 'random' | 'all';
  effect: EffectPart[];
  // 时机不进数据：轮班·限时=立即，世界·即时=下回合，由运行时按模式决定
}

interface EffectPart {
  type: 'move' | 'back' | 'skip'      // 前进N / 回退N / 罚停N回合
      | 'hp' | 'drawItem' | 'discardItem' | 'banItem'
      | 'diceMod' | 'reroll' | 'immune'   // 下骰±N / 重掷当前 / 免疫卡牌效果
      | 'coinFlip' | 'trial' | 'none';    // 二选一随机判定 / 再抽一张事件卡
  value?: number;
  then?: EffectPart[];        // coinFlip 复用：正面/反面各自的后续
}

interface ItemCard {
  id: string;
  title: string;
  flavor: string;
  target: 'self' | 'other';   // other 的具体目标由卡面 target 选择器指认
  effect: CardEffect;
}
```

陷阱格是格子属性：`{ type: 'trap', effect: EffectPart[] }`，不走卡池。

## 五、交互机制增补（玩家对抗与交互机制定案 #10）

> 本节来自 [#10](https://github.com/shanchahuaA/party_flight_chess/issues/10) 的拷问定案，修订上文部分条款；完整派对模式骨架见《[MVP一页纸规则](MVP一页纸规则.md)》v2。

### 5.1 血量与淘汰（修订 1.4）

- 血量上限 3 → **10**（开局可调；陷阱/事件/治疗的扣血与回复数值进数值票重校）。
- **血尽 = 淘汰**（推翻 1.4「血尽 = 轮空满血复活」）：死了就死了；淘汰者进入观战（看全局、发表情/弹幕），不影响局面，不再被指认为效果目标。
- 暗牌目标终局统一判定：淘汰不免除已达成的事实，「活到结算」类目标自然失败。

### 5.2 道具卡目标类型学（修订 1.5）

1.5 中「道具卡目标由系统指认」表述作废。目标**按卡定义**，类型五分：

- `self`：作用于自己（治疗、加速）。
- `chooseOther` **自选型**：打出时弹目标选择器，指任意在场玩家（弹弓、脚镣、偷天换日）。
- `auto` **自动指认型**：卡面写死指认规则、系统执行（如「身后最近的人」）。
- `allOthers` **全体型**：影响所有其他玩家。首批新增 1 张「惊雷」（所有其他人回退 1），道具池 12 → **13** 张。
- `ground` **场地型**：打出后附着在当前格，**下一个踩上该格的玩家吃效果（含铺设者本人）**。香蕉皮改为场地型（罚停 1 回合），道具表同步改。

事件卡维持系统指认不变；指认规则跳过淘汰者与通关席玩家。

### 5.3 违禁标记（新增字段）

道具卡新增 `contraband?: boolean`：整蛊类道具卡 = 违禁品，用于警长查货窗的报备与查验判定。

### 5.4 自由窗口型事件（新增类别）

- `kind` 增加 `'window'`：抽到后把当前世界回合窗变为特殊窗口，效果作用于全体，不受「抉择卡弹给本人」流程约束。
- 首批 1 张：**黑市开张（警长查货窗）**——随机警长/偷渡者报备转让/谎报违禁/查验 ≤2 次（6 人以上局 3 次）/说谎罚 1 张自选道具卡（无卡回退 3 格）/查验清白警长反赔 1 张/警长超时退化为自由转让。完整规则见一页纸规则 v2「警长查货窗」节。
- 事件卡池 20 → **21** 张（14 抉择 + 6 纯效果 + 1 自由窗口）。

### 5.5 暗牌目标系统（新增）

- 开局每人从目标池（首批 8–12 条）**抽 2 选 1**，**暗牌**（对他人保密），终局亮牌。
- 达成 = 获**称号** + 积分（权重进数值票）；**最后一波世界恶意团灭 → 全员目标作废**（群体失败闸门，接棒原「回合帽门未开」挂点——boss 门闩已撤出派对模式）。
- 数据结构草案：

```ts
interface GoalCard {
  id: string;
  title: string;        // 目标名（终局亮牌展示）
  hint: string;         // 一句话描述
  check: GoalCheck;     // 判定条件，走对局事件计数
  badge: string;        // 称号文案
  score: number;        // 积分（数值票定）
}

// GoalCheck 依赖对局计数器：坑人次数、赌狗胜场、结算手牌数、
// 是否通关、是否活到结算、警长窗违规次数等，实现时由对局事件流汇总。
```

### 5.6 世界恶意（新增，世界层机制）

- 周期性全局负面事件：**不是卡、不是格**，是世界层机制（节奏/强度/具体演出原型票裁决，例：天降大木头、随机滚石、地板塌陷区）。
- **最后一波** = 局长打完后的终局布景，形态 **A 各自过波**（每人掷骰+道具扛）vs **B 合力大怪**（全员削共享血条），原型票实玩二选一。

### 5.7 棋盘重排（52 → 80 格）

- 格子类型重排：**事件 32 ｜ 道具 16 ｜ 陷阱 12 ｜ 空格 20**（4 色分区每区 20 格）。
- 陷阱格 8 → 12，效果分布数值票重排；拓扑仍是环，视觉弯弯绕绕，岔路格待原型票验证。
