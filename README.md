# 🏮 庄园法会 · 春节派对飞行棋

2–8 人手机网页派对游戏：大富翁式庄园路网上掷骰走格 + 事件卡整活 + 世界恶意 + 跑团检定。每人手机打开链接即玩，无需下载、无需注册。一局约 10–15 分钟。

> 玩法规则一页看完：[docs/MVP一页纸规则.md](docs/MVP一页纸规则.md)；数值口径：[docs/内容数值表.md](docs/内容数值表.md)。

## 🎮 怎么玩（M1 单机版）

**打开即玩**：https://shanchahuaa.github.io/party_flight_chess/

1. **开局配置**——同桌几人（1 真人 + 1–7 假人）、局长回合数、血量上限、世界回合窗、计时模式、回合间休息、世界恶意档位；给自己挑一个角色（三轴 6 点+被动，明选可重复）。
2. **抽暗牌**——从 2 条目标里选 1 条保密；选完第一窗开张。
3. **每个世界回合**——（可选）打道具卡 → 掷走格骰 1d10 → 逐格走、落格触发（事件/道具/陷阱检定/野狗遭遇战）→ 点「确认结束」。
4. **局长打满**（默认 15 回合）——终局最后一波：全员合砍年兽（1d12 伤害骰、每波反噬全场），赢了或团灭都进结算。
5. **结算页**——五项积分透明分账+排名、暗牌亮牌（称号+8/条）、群体失败盖章、找战犯（点击证据条目可跳回战报原文）；「再来一局」原桌原配置换新种子，或回大厅重调配置。

### 两种计时模式

- **世界·即时**（默认）：全员在同一倒计时窗内同时行动，全员确认提前开窗；有人超时，系统替他掷骰并自动确认（不替打卡）。
- **轮班·限时**：按座次轮流行动，轮到谁谁的倒计时才开始走；淘汰者与通关席跳过轮次，超时自动掷骰+自动确认。适合更"桌面棋"的节奏。

### 手机小贴士

- 页面切后台再回来：本地计时暂停，从冻结处继续（不补算后台时段）——放心切出去回消息。
- 微信内置浏览器能玩即达标；遇到渲染异常建议点右上角「用系统浏览器打开」。
- 血尽出局=观战（棋盘变暗+☠），不再掷骰打卡，但战报照样精彩，等结算一起算总账。
